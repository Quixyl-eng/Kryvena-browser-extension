# kryvena

Самодостаточное Manifest V2 расширение для Orion на iOS/iPadOS.

## Установка

1. Скопируйте содержимое этой папки в архив ZIP без внешней папки.
2. Переименуйте архив в `.crx` для режима Chrome или `.xpi` для режима Firefox.
3. В Orion откройте «Расширения» → «Установить из файла» и выберите архив.

Автообновление не используется. Для работы запросов расширению разрешены `storage` и сетевые URL. Background page оставлена постоянной: это уменьшает вероятность потери запроса при выгрузке вкладки на iOS.

## Настройка

Откройте popup расширения, выберите провайдера и сохраните API-ключ. Список моделей загружается автоматически через background по API-ключу; для кастомного провайдера укажите URL OpenAI-compatible endpoint. Поддерживаются и полный адрес `/v1/chat/completions`, и базовый адрес `/v1` — последний автоматически дополняется для запросов и списка моделей. Перед сохранением можно нажать «Проверить соединение»: тест использует текущие поля формы и не требует сначала сохранять ключ. Ключ очищается от случайных пробелов/кавычек, хранится в `chrome.storage.local` и не выводится в интерфейс страницы.

Нажмите на маленькую стеклянную полоску, чтобы расширение без открытия панели отправило текущий вопрос в выбранную модель и отметило ответ. Кнопка «Далее» никогда не нажимается автоматически: после выбора расширение ждёт, пока пользователь сам перейдёт к следующему вопросу. При обнаружении страницы результатов автоматический режим отключается и интерфейс скрывается; панель открывается только при ошибке, чтобы показать её причину.

## Ограничения iOS

WebKit не предоставляет content script доступ к физическим кнопкам громкости и не генерирует для них DOM-события. Поэтому едва заметная стеклянная полоска показывается сразу после загрузки страницы. Три быстрых касания/клика по странице скрывают её и останавливают автоматический режим; ещё три касания возвращают полоску. Нажатие на неё запускает обработку текущего вопроса. Надёжно отследить именно кнопку громкости без нативного API Orion невозможно.

Селекторы TestPad сделаны эвристическими, поскольку разметка конкретных тестов может отличаться. Стартовые поля участника (имя, фамилия, ФИО) распознаются отдельно: панель закрывается, поля остаются доступными для ручного ввода, и они не отправляются в LLM. Реклама отбрасывается по DOM-признакам и текстовым признакам и не включается в варианты.

Расширение использует callback-форму Chrome API, `chrome.storage.local`, touchend/click fallback и vendor-prefixed WebKit CSS. Эти решения нужны для совместимости с iOS WebKit и не требуют сторонних библиотек.
